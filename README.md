# NJUCM 校园网无感认证

自动登录南京中医药大学校园网认证系统（`net.njucm.edu.cn`「网络接入认证系统」）。装好后，连上校园网会自动完成 Web 认证，开机、联网、断线重连都不需要再打开浏览器。

> 采用相同认证系统（`/api/portal/v1/login` 接口风格）的其他学校也可以使用，修改 `login.ps1` 顶部的 `$Portal` 地址即可。

## 原理

通过分析认证页 JS 得出的接口调用：

| 接口 | 用途 |
|---|---|
| `GET /api/portal/v1/getinfo` | 查询本机是否已在线（已在线则脚本直接退出，不重复登录） |
| `POST /api/portal/v1/login` | 提交 `{domain, username, password}`（PAP），被拒自动回退 CHAP（challenge + MD5） |
| `GET /api/portal/v1/challenge` | CHAP 模式取随机质询串 |

网关按源 IP 识别设备，因此脚本必须运行在需要认证的那台电脑上。密码通过 Windows DPAPI 加密保存（`cred.bin`），仅当前 Windows 用户可解密。

## 安装

1. 下载本仓库（Code → Download ZIP，解压到任意固定位置，**之后不要移动文件夹**，计划任务指向该路径）；
2. 双击 `1-配置账号.cmd`，按提示输入上网账号、选择运营商域、输入密码（密码输入不回显）；
3. 双击 `2-安装开机自启.cmd`，注册计划任务并自动试运行一次。

完成。此后连上校园网即自动认证，结果写入 `login.log`，可用 `3-立即测试.cmd` 随时手动验证。

计划任务 `NJUCM-CampusAutoLogin` 的触发时机：用户登录（延迟 15s）、网络接通（延迟 20s）、每 10 分钟兜底（睡眠唤醒 / 被踢下线后自动补登）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `1-配置账号.cmd` | 保存账号密码（只需运行一次） |
| `2-安装开机自启.cmd` | 注册计划任务 |
| `3-立即测试.cmd` | 手动执行一次登录并显示结果 |
| `卸载.cmd` | 删除计划任务 |
| `login.ps1` | 核心登录脚本 |
| `setup.ps1` / `install-task.ps1` / `uninstall-task.ps1` | 被 cmd 调用的实际逻辑 |
| `config.example.json` | 配置模板（复制为 `config.json` 可跳过交互输入账号域） |

运行后本机生成的文件（均已被 `.gitignore` 排除，请勿提交）：

| 文件 | 说明 |
|---|---|
| `config.json` | 账号与运营商域（default=校园网 / cmcc=移动 / telecom=电信 / unicom=联通） |
| `cred.bin` | DPAPI 加密的密码 |
| `login.log` | 登录日志 |
| `lastfail.txt` | 认证失败冷却标记（1 小时内不重试，防止锁号） |
| `PAUSE.txt` | 手动新建即暂停自动登录，删除即恢复 |

## 常见问题

- **提示并发上限 / E013 / E002**：账号在别的设备在线，先在认证页「当前在线」里下线其他设备。
- **改了统一身份认证密码**：重跑 `1-配置账号.cmd`。
- **登录一直失败**：查看 `login.log` 中的错误码；部分账号需要把域改为 `default`（校园网）。
- **想临时手动控制上线**：新建 `PAUSE.txt`。
- **学校原生无感**：认证成功页面本身有「无感知认证」标签页（MAC 绑定自动上线，最多 30 台设备），与本脚本二选一即可，同时用也不冲突。
